# Loop

Estudio de loops en el navegador, instalable como app (PWA): batería, bajo, sinte y acordes, con mixer, efectos y master con volumen automático. También genera un loop distinto a partir de cualquier nombre.

```bash
npm install
npm run dev
```

Para instalarla en el celular: abrí la app publicada y elegí "Agregar a pantalla de inicio" (en iPhone, desde Safari con el botón Compartir).

Los samples de batería (`public/samples/`) son el set TR-909 de Rob Roy Recordings: uso libre sin fines de lucro y sin modificarlos. Ver `public/samples/TR909SET.TXT`.
